# OpenSanctions / yente

## Teknologi
`opensanctions/yente` er en åpen matching/search API for FollowTheMoney entities og kan kjøres on-premise med egne datasett. Koden er MIT-lisensiert.

## Data
OpenSanctions-produserte datafiler er publisert under CC BY-NC 4.0 for ikke-kommersiell bruk. OpenSanctions opplyser at bruk i en for-profit virksomhet krever datalisens, også når data brukes via egen infrastruktur.

## Analysen-policy
- yente-kode kan evalueres uavhengig av OpenSanctions-data.
- Egne BRREG/FtM-datasett kan matches lokalt.
- OpenSanctions bulkdata er `enabled: false` inntil prosjektets bruk er avklart som ikke-kommersielt eller riktig lisens foreligger.
- Offisielle EU-sanctions data kan integreres direkte som egen Tier-1 kilde uten å være avhengig av OpenSanctions.
