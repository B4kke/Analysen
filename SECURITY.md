# Security

Ikke publiser sikkerhetssårbarheter som inneholder secrets eller persondata i en offentlig issue. Se `docs/SECURITY.md` og `docs/THREAT_MODEL.md` for systemets sikkerhetsmodell.

Analysen behandler eksternt nettinnhold som ubetrodd data og skal ikke omgå tilgangskontroll, CAPTCHA, betalingsmur eller privat autentisering.
